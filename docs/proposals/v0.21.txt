Kubio kubio.json v0.21 Proposal
Status: Under review
Base: v0.20


1. Scope candidates

v0.21 is the next planning container for capabilities deferred from v0.19
and v0.20. No item in this file is an agreed v0.21 feature yet. The final
scope must be narrowed and specified before promotion.


2. Deferred capabilities

- Client certificates, mutual TLS, TLS passthrough, configurable upstream TLS
  policy, ACME, multiple listener certificates, and listener SNI certificate
  selection.
- Configurable logs, request IDs, metrics, health/admin/reload endpoints.
- Forwarded and PROXY protocols, URI rewrites, redirects, fixed responses,
  and custom error bodies.
- Rate limiting, authentication, compression, caching, service discovery,
  response trailers, conditional response headers, request-header policies,
  adaptive retry policies, and policies for Kubio-generated or intermediate
  responses.


3. Planning constraints

The selected feature must preserve strict kubio.json validation, atomic reload
failure behavior, generation isolation, and the concise option naming policy.
Unselected capabilities remain deferred to a later proposal.
